EQCOMM — AMI Access Point Install

Internal jobs to install AMI (Advanced Metering Infrastructure) communication access points or relay devices on existing poles. Assigned by work management — not customer-generated. Fast, simple, low cost. Usually self-approvable.

● Internal Job No Customer Contact Self-Approvable (~$800) No Barricade Needed WO Pre-Created
What Is This Job
BACKGROUND

EQCOMM (Equipment Communication) jobs install AMI communication nodes on the distribution system. AP stands for Access Point. These devices connect to Entergy's smart grid communication network — allowing meters and field equipment to communicate back to operations systems. Three types exist: Verizon-networked APs, AT&T-networked APs, and Entergy's own mesh network relays. The job details in Maximo will tell you which pole and which device type. You fill in the existing WO — you do not create one.

Transformer Decision Tree

The AP needs power. Before designing, look up the assigned pole in GDT/Epoch and answer this question: Is there a transformer on or near this pole?

✓
IF — Transformer is on the assigned pole
Good to go. Install AP on that pole.
No additional design work needed. Place CU on pole, add tailboard, build sketch, send to construction.
~
IF — No transformer on pole, but one is 1–2 spans away
Run triplex to the assigned pole.
Design a secondary triplex run (A10T) from the nearby transformer to the assigned pole. Add appropriate secondary CUs for the run plus the AP CU on the assigned pole.
+
IF — No transformer anywhere nearby in the area
Install a new transformer on or near the assigned pole.
Size transformer appropriately for the load (small single-phase — TS25-8 or similar). Add transformer CU, secondary CUs as needed, and AP CU. This scenario is less common — confirm with supervisor if unsure.
CU Selection — Pick One Based on Job Type

The Maximo WO description will tell you which device type. Pick the matching CU. There is no visual icon in GDT — just place the CU on the pole.

Verizon Network
AMI-AP-VERIZON
Verizon-networked AMI access point. WO description will reference Verizon or contain Verizon-specific device info.
AT&T Network
AMI-AP-ATT
AT&T-networked AMI access point. WO description will reference AT&T or contain AT&T-specific device info.
Entergy Mesh / Regular
AMI-RELAY
Entergy's own mesh network relay. WO will reference "regular" or "mesh." Most common internal AMI job type.

Step-by-Step Workflow
01
Open WO in Maximo
WO is pre-created and assigned to you. Open it and read the description carefully — it will tell you which pole to use and which AMI device type is being installed. Fill in designer field, set to WDESIGN.
02
Look Up the Pole in GDT / Epoch
Navigate to the DLOC. Find the assigned pole. Check for a transformer — is it on the pole? On a nearby pole? Nowhere close? This determines your design path. Set GDT to Design status.
03
Identify Upstream Device
Find and capture the upstream device in Maximo. Note feeder, G-zero, and upstream device details. This is standard for every job regardless of type.
04
Apply the Transformer Decision
Transformer on pole → proceed. Transformer 1–2 spans away → design triplex run using A10T secondary and appropriate secondary dead end CUs. No transformer in area → add transformer CU (typically TS25-8).
05
Place CU on the Pole in GDT
Place AMI-AP-VERIZON, AMI-AP-ATT, or AMI-RELAY directly on the assigned pole. There is no icon or symbol for these in GDT — just the CU placed on the pole. Add TAILBOARD-OH. Save.
06
Send Design, Run Estimation
Send design from GDT to Maximo. Run estimation. Check costs tab. These jobs typically run around $800 — well under the self-approval threshold.
07
Complete Sketch and Vicinity Map
Build job sketch showing pole location, upstream device, and AP placement. Complete vicinity map. Attach photos if applicable. These are still required even on simple jobs.
08
Run Reports and Complete Log
Run standard reports: Material Summary, Job Cost Summary, As-Built. Complete WO log: Purpose and Necessity, Capital vs O&M designation, Work Description. Import all files into Maximo.
09
Self-Approve and Send to Construction
Because cost is typically ~$800, you can approve this yourself — no supervisor routing required. Perform acceptance, approve in Maximo, set GDT to Approved. Deliver job packet to construction.
Things to Know
✓
Self-approvable. These jobs typically cost around $800. You do not need to route to your supervisor for approval — you can perform acceptance and approve yourself in Maximo.
⚠
No GDT icon for AMI CUs. There is no visual symbol or icon to place in GDT for these devices. You simply place the CU code on the pole. Do not spend time looking for a symbol that does not exist.
⚠
No barricade CU needed. Unlike most energized OH work, EQCOMM jobs do not require TRUCK-BARRICADE-OH. Tailboard only. This is one of the few job types where this applies.
ℹ
WO is pre-created. You do not create a new work order for EQCOMM jobs. One is assigned and waiting for you. Open it, fill it in, and route it.
ℹ
Check the WO description carefully. The pole number and AMI device type are both in the Maximo WO description. Read it before opening GDT — it tells you everything you need to start the design.
Common Mistakes
✗ ADDING BARRICADE CU

These jobs do not require TRUCK-BARRICADE-OH. Tailboard only. Adding the barricade CU inflates cost unnecessarily.

✗ ROUTING FOR APPROVAL UNNECESSARILY

At ~$800 these are self-approvable. No need to wait for supervisor approval — you can approve yourself and move straight to construction.

✗ WRONG AMI CU

Three CU options exist. Read the WO description to identify Verizon, AT&T, or mesh before placing your CU. Wrong CU = wrong material ordered.

✗ SKIPPING TRANSFORMER CHECK

The AP needs power. Always check whether a transformer is on or near the assigned pole before finalizing your design. Missing this step means a job that cannot be built.
